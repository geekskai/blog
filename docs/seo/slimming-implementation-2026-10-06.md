## 已完成

1. 将4篇P0文章移出发布目录，原文保存在 `docs/content-archive/2026-10-06/`。本地旧URL均404，sitemap移除；不跳转到无关页面。内容生成从168篇博客变为164篇，其中仍有1篇草稿。
2. 六篇MDX的11处Base64图片引用改为9个去重后的独立PNG，位于 `public/static/images/blog/embedded/`。校验解码字节完全一致，未重绘或有损压缩。MDX减少1,816,275字节，新增PNG共1,262,635字节，源码+图片净减少553,640字节；主要收益还包括HTML、内容数据和RSS不再反复嵌入Base64。
3. RSS使用摘要与文章链接，按发布日期倒序，主feed和每个tag最多30篇，过滤草稿，正确转义XML；空tag写空feed。修复原来的同步调用未等待async生成函数问题：现在生成器同步执行，错误会直接使构建失败。未递归删除不明tag目录。
4. 新增 `npm run archive:source`：输出到系统临时目录，排除依赖、构建产物、Git、常见凭证、本地环境配置和生成RSS，保留锁文件与环境模板。运行需Python3。**这是常见文件规则过滤，不是完整秘密扫描，分享前仍需检查。**不依赖Git存在。
5. 新增 `npm run test:rss`，测试摘要输出、30篇上限、倒序、草稿过滤、XML转义、空feed与输入不被修改。

构建后主RSS22,681字节，335个RSS合计644,815字节。源码归档实测约89.8MB（具体值随文件变化），不包含本地安装依赖和构建缓存。
