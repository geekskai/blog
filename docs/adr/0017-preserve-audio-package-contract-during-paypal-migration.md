# Preserve the Audio Toolkit package contract during the PayPal migration

The processor migration preserves the existing Audio Toolkit contract: Free supports one file without ZIP export, Basic supports 20 files at $10 monthly or $96 annually, and Pro supports 50 files at $25 monthly or $240 annually; only the four paid tier-and-interval combinations become PayPal Plans. Each account keeps one 14-day full-refund window after its first successful subscription payment, handled manually in v1, so changing the payment rail does not silently redesign pricing, entitlements, or the customer promise.
