# Reward X share intent without claiming verification

The first growth-loop release grants Share Unlock when a person opens the prepared X share composer, at most once per Quota Day. A normal X Web Intent does not prove that a post was published, so product copy and analytics describe this as `share_intent_opened`, never as a verified or published share. We avoid X OAuth and API verification because the additional authorization friction is disproportionate to a five-download reward; server-side daily enforcement still applies to Registered Users.
