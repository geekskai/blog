# Use hybrid authority for daily download allowances

Visitors keep a device-local Daily Download Allowance so public tools remain immediately usable without an account or anonymous server identity. Registered Users use a server-authoritative allowance keyed by their authenticated identity, including Share Unlock issuance, so their entitlement is consistent across devices, measurable, and resistant to client-side resets. On registration, the client reports the Visitor's current-day usage and the server clamps it to 0 through 3 before initializing registered usage; this preserves the promised seven-download increase instead of resetting the day. We accept that Visitors can still reset or under-report local state because preventing at most three extra downloads would add identity and privacy costs before registration.
