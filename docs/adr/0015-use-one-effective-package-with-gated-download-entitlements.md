# Use one effective package with gated download entitlements

Geekskai presents Free, Basic, Pro, and Enterprise as Package Tiers while Creem sells only the Basic and Pro monthly and annual products. Each Clerk account has one Effective Package: a manual Enterprise grant takes precedence over a verified Creem subscription, which takes precedence over Free. Webhooks map trusted server-side product IDs to Package Tier and Billing Interval, then synchronize stable Account Entitlements; checkout input never accepts a Product ID. Basic and Pro may store download allowance and concurrency entitlements, but runtime download services ignore those paid values unless `PAID_DOWNLOAD_QUOTAS_ENABLED=true`. That switch must remain disabled until Creem gives written approval for paid downloader allowances. Before approval, public pricing and checkout sell only local Audio Toolkit capabilities, while downloader allowances remain on the Visitor and Free rules. This preserves the planned domain model without representing a prohibited or unapproved paid capability.
