# Use one effective package with gated download entitlements

Geekskai presents Free, Basic, and Pro as Audio Toolkit Package Tiers. Creem sells only the Basic and Pro monthly and annual products. Each Clerk account has one Effective Package: a verified Creem subscription takes precedence over Free. Webhooks map trusted server-side product IDs to Package Tier and Billing Interval, then synchronize only the stable Audio Toolkit Account Entitlements; checkout input never accepts a Product ID.

Public third-party downloader tools are a separate free product surface. Billing does not store, grant, gate, or advertise downloader allowance, concurrency, or Share Unlock changes. Every Registered User follows the same downloader quota rules regardless of Audio Toolkit Package Tier. This separation is permanent for this product model, not an environment-gated release stage.
